    03 Installer

    Put it on your FM-1.

    The installer writes MRC Synth to the instrument from the browser. No tools, no drivers, and a way back to the official firmware if you want it.

    1

    Plug it in

    Connect the FM-1 straight to the computer with a USB data cable, no hub.

    2

    Press Install

    In Chrome or Edge, allow MIDI. Keep the cable in while it writes.

    3

    Play

    It restarts into MRC Synth. Then open the editor to shape it from here.
